# Audit tampilan jurusan dan informasi jurusan jurnal

Mode: setelah implementasi, sesuai pilihan pengguna. Dokumen ini merekam kondisi sebelum perbaikan. Pengguna kemudian menyetujui pengerjaan temuan 1–4 melalui pesan "do it"; hasil audit ulang dicatat pada laporan lanjutan.

Status terbaru: keempat temuan sudah diselesaikan. Bukti dan Delivery Gate: [`audit-002-2026-10-07.md`](audit-002-2026-10-07.md).

## Ruang lingkup dan arah

- Halaman baru `resources/views/admin/jurusan/`, menu jurusan, serta informasi jurusan siswa pengisi pada detail, histori, dan laporan jurnal.
- Mengikuti komponen aplikasi yang sudah ada, tanpa redesign, aset baru, atau perubahan tema.
- Pembacaan desain: aplikasi administrasi sekolah untuk admin dan guru, dengan bahasa visual hijau/olive aplikasi. ENERGY 1 / RHYTHM 1 / MOTION 1.
- Hijau dipertahankan agar aksi utama konsisten dengan aplikasi; chip menunjukkan status aktif dari database, bukan dekorasi.
- Tabel dipakai untuk membandingkan kode, nama, bidang, dan jumlah referensi; jumlah berasal dari query database.
- Formulir memakai field dan tipografi Inter yang sudah ada agar pengelolaan jurusan tidak terasa sebagai aplikasi berbeda.
- Bagian hapus dipisahkan dari form ubah untuk membedakan tindakan destruktif dari penyimpanan biasa.

## Temuan bernomor

1. **HIGH, R-25: beberapa warna teks komponen bersama belum memenuhi kontras AA.** `resources/sass/app.scss:901` memakai `--n-600` (`#7c7c7c`) untuk petunjuk kecil pada putih, sekitar 4,17:1; `:903` dan `:304` memakai `--red-100` (`#fb3748`) untuk teks error/hapus, sekitar 3,66:1. Minimum teks kecil adalah 4,5:1. Warna diwarisi halaman jurusan, bukan ditambahkan oleh fitur ini. Rasio dihitung dari token mode terang, mode gelap belum diuji langsung.
2. **HIGH, R-03: tinggi kontrol baru masih mengikuti ukuran 36px komponen bersama.** `resources/sass/app.scss:269` mengatur tinggi tombol/input/select sebesar 36px, di bawah target sentuh 44px. Formulir jurusan menggunakan komponen tersebut tanpa override. Audit tampilan pada perangkat nyata masih diperlukan.
3. **HIGH, R-27: belum ada indikator pemrosesan khusus untuk submit jurusan dan filter.** Empty state tersedia di daftar dan validasi ditampilkan lewat `x-field`, tetapi belum ada status sibuk pada formulir baru. Navigasi penuh memiliki indikator browser, bukan status pemrosesan di dalam aplikasi.
4. **HIGH, R-35/R-32/R-34: bukti click-through, keyboard, mobile, dan kedua tema belum lengkap.** Browser desktop tidak terhubung ke sesi. Pengujian HTTP dan feature test tidak membuktikan layout, fokus visual, kontras seluruh elemen, atau console JavaScript.

## Bukti fungsi yang tersedia

Bukti ini merupakan HTTP/feature test, bukan click-through browser:

| Kontrol/alur | Bukti |
| --- | --- |
| Menu/daftar jurusan | GET `/admin/jurusan` menghasilkan HTTP 200 setelah login admin pada aplikasi Docker. |
| Tambah jurusan | GET `/admin/jurusan/create` HTTP 200; POST tervalidasi menyimpan kode kapital lewat procedure pada MySQL dan transaksi portabel pada SQLite. |
| Formulir tidak valid | Test menolak kode kosong, whitespace di awal/akhir/tengah, kode panjang, nama kosong, bidang panjang, dan status tidak valid. |
| Filter | Test memeriksa pencarian, bidang, status nonaktif, dan sorting; daftar memakai paginator aplikasi. |
| Ubah jurusan | GET `/admin/jurusan/TKJ/edit` HTTP 200; test memeriksa unique-ignore dan cascade kode ke kelas/siswa. |
| Hapus jurusan | Test membuktikan jurusan tidak terpakai dapat dihapus dan jurusan berreferensi ditolak; checkbox konfirmasi adalah kontrol HTML native. |
| Detail/histori/laporan jurnal | Feature test memeriksa informasi jurusan; GET `/jurnal` dan `/admin/laporan/jurnal` HTTP 200 di aplikasi Docker. |
| Build | `docker compose run --rm --no-deps bun bun run build` berhasil. Build lokal Windows terkendala native binding rolldown; tidak ada perubahan dependency untuk mengatasinya. |
