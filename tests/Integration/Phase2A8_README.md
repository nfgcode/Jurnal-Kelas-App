# Phase 2A.8 disposable MySQL verification

Run from repository root: `python tests/Integration/Phase2A8_runner.py`.
Requires existing local `mysql:8.0` and `jurnal-kelas-app-app` images, Docker, Python. No install, pull, Compose, development DB connection, restore, or source mutation. Allow several minutes for the safety foundation.

The runner first runs only `SafetyFoundationTest.php` and `SafetyApplicationTest.php` in a fresh read-only PHP container with no network. It then creates a randomly labelled internal-only network, MySQL with tmpfs `/var/lib/mysql`, and a distinct read-only PHP runner. Neither publishes ports; the runner can reach only its owned MySQL. Credentials are random per run, never copied from application settings; temporary credential files are removed. Docker inspect output is parsed internally; environment values are not printed.

Before mutations: exact run labels, pinned image identities, exact network membership, internal network, no published DB ports, no persistent DB volumes, and tmpfs are checked. Each PHP process checks the expected random DB name and server UUID. Laravel receives forced test configuration, no project `.env`, isolated writable storage/manifests/caches under `/scratch`; project mount remains read-only. Legacy `mysql_guard.php` remains unchanged.

Coverage: complete ordered empty-schema migration chain (stored functions/procedures included); latest two migration down/re-up preserving fixture rows; generated unique active-year/membership constraints; six historical FK RESTRICT definitions. Concurrency uses separate PHP processes, file barriers, coordinator-held singleton lock, and `performance_schema.data_locks` WAITING plus `data_lock_waits` evidence for every participant before release. Cases: different activation targets, same encrypted snapshot double execution, future planned placement rejected before destination start, master model edit overlapping activation. Raw-delete checks exercise historical FK rejection, not only metadata. No sleep-only race claims. Synthetic fixtures only; deterministic domain clock `2027-07-01` in concurrency scripts.

Structural overlap additionally covers destination period start edit, destination class year edit, and department deactivation, separately. Each case first proves the unchanged activation succeeds in a rollback-only transaction. The coordinator proves the real model writer WAITING, releases it to save inside its owned transaction, starts the real activation service, proves its WAITING lock edge specifically names that master connection, then permits master commit. All three committed invalidations must reject activation while preserving period/student/membership/transition invariants. No application mocks or replacement service calls. Generated column metadata, computed values, uniqueness, and fixture preservation are checked after migration cycles.

Results: absolute `results.json` path printed at exit; contains real identity, counts, waits, final state, cleanup, before/after SHA-256 source manifests for application PHP, migration PHP, and integration PHP/Python. Source drift fails the run. Cleanup removes only exact names whose labels match this random run token, then verifies absence. Forced process/host termination can interrupt cleanup: inspect exact named resources and label before removing; never prune shared Docker resources.

Baseline snapshot: `C:/Users/Tenma/AppData/Local/hermes/cache/scratch/phase2a8-baseline.json`; SHA-256 for readable pre-existing files including dependencies; five inaccessible Windows node_modules executable link stubs recorded separately, not silently omitted. Captured before harness edits. Parent independently holds its initial git snapshot. No application source files owned by this harness.

Residual boundary: model/controller serialization is cooperative. Bulk query-builder updates, direct SQL, external writers, and privileged DB clients can bypass the singleton; only the generated unique indexes and FK constraints remain database-enforced against those writers. These checks do not claim universal raw-write immutability or controller/browser coverage.
